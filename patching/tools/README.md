# patching/tools

Node ≥ 22.18 TypeScript, run directly (`node <file>.ts`), no framework. Tests live in
`test/*.test.ts` (`npm test` here; the root `npm test` runs them too). Shared helpers in `src/`.

| Tool | Does | Usage |
|---|---|---|
| `patch-compile.ts` | Headless sclang parse check of a personality (~3 s, a throwaway sclang on 57190 that compiles the file and exits; the patch is never executed), over `compileCheck` in `src/sc.ts`, which removes its throwaway `.scd` every time. A bare name resolves to `airkit/personalities/<Name>.sc` (`COS_REPO_ROOT` honoured); a path — the `.sc.tmp` edit copy before the `mv` — is used as given. Prints `<file>: parses`, or the error context and `<file>: does not parse`. Exit 0 parses, 1 doesn't, 2 usage, no such file, or no sclang (`COS_SCLANG` overrides its path). | `npm run patch:compile -- <Name\|path>` |
| `corpus-mine.ts` | Mines `personalities/`/`synths/` off every AirKit branch via git objects only (nothing checked out); writes `patching/corpus/index.json`, `INDEX.md`, `stats.md` and the raw copies (`digest.md` is written by hand from them, not by the tool). Before re-mining after Steph pushes: `git -C airkit fetch origin` (it reads `origin/<branch>` refs). A re-mine can change raw line numbers that the skill's references and `digest.md` cite — run `npm test` (the citations test checks every pointer). | `npm run corpus:mine` |
| `patch-lint.ts` | Static rule check of a personality, parameterised by `patching/profile.md` front-matter (`--profile` overrides): header keys and gesture words, `COS_` / `2H` naming, required hooks and `\silent`, scene-param hooks, `~partner` guards, tick-thread safety, banned globals/server control/absolute paths, sample paths from `cosSamples`, SynthDef prefix/duplicate/collision (other personalities + engine), unknown classes (SCClassLibrary + Extensions incl. sc3-plugins), roster membership. Prints `[E]`/`[W] rule.id — file:line — message`; `--json` gives `[{id, severity, file, line, message}]`. Exit 0 no errors, 1 errors, 2 usage/missing file. | `npm run patch:lint -- <Name\|path> [--json]` |
| `patch-roster.ts` | Adds, removes or lists patches in `airkit/lists/list_conditions.sc`, atomically, keeping the `silence` bookends. `add` refuses a name with no `airkit/personalities/<Name>.sc`. Exit 0 ok, 1 `<Name>` doesn't match `COS_UpperCamel` or (add) its file is missing, 2 usage. | `npm run patch:roster -- add\|remove <Name>` / `npm run patch:roster -- list` |
| `take-record.ts` | Records one stick's raw IMU stream (resolved by `--wrist` through `scenes/cast.yaml`, or `--id` directly) from UDP `--port` (default 8001: repoint the stick with `/Config/RequestStream`, or stop the runner and use 8000 — root `README.md`, "Recording a take") to `takes/<label>.take.jsonl`; appends a row to `takes/INDEX.md`. Stops on `--seconds`, Ctrl-C, or 5 s of stream silence. Warns on stderr if no packet arrives within 3 s. Labels must match `^[A-Za-z0-9_.-]+$`; an existing label is refused unless `--force` (which replaces the file and its INDEX row). A take with 0 rows writes neither the file nor the row. Exit 0 written, 1 no packets / label exists / could not start, 2 usage. | `npm run take:record -- <label> --wrist ZL\|--id 3 [--seconds 30] [--port 8001] [--what "…"] [--force]` |
| `patch-audition.ts` | Plays a patch on the engine's audition slot 9 through a private device: streams `/9/IMUFusedData` from its own source port (`--src`, default 9101 → device port 9109, index 9, sharing slot 9's bus and monitor — never 9001, never slots 1–8), sets slot-9 params (`--params k=v,…`; none = cleared — for a runner auditioning on slot 9 too), partner 0 (so a `2H` patch runs with `~partner` nil) and audition level 1 (set, not restored: it is left at 1), loads the patch, waits `ready`, drives synthetic phases (default; `--quick`, `--long` adds a 60 s preloaded-at-level-0 still before the shake) or a recorded take (`--take <label>`, `takes/<label>.take.jsonl`), then loads `silence` on 9109, checks silence within 1 s, leaves the audition level at 1, and scans the engine log for `ERROR`/`not understood`/`DoesNotUnderstand`/`FAILURE` written during the audition (not the boot). Every levels message counts toward the clip ceiling (0.98) and the shake/strike onset floor; quiet phases ignore their first 0.5 s for release tails when judged against their rest ceiling — 0.02 (−34 dBFS) by default, `--rest-max <dBFS>` for a patch designed to sound at rest; the after-unload silence check (< 0.01) never moves. Prints a `rest ceiling … dBFS` line, `phase \| seconds \| peak dBFS \| rms dBFS \| verdict`, `server cpu (max) NN %` (max-held `serverCpu` from the status polls during the phases), and `AUDITION PASS`/`FAIL`. `--engine auto` (default) uses the engine on 57120 if it answers `getStatus` within 1 s, else boots a private one on 57130/57131 (log `~/.conditions/audition.log`, killed on exit unless `--keep`). It polls `getStatus` at 5 Hz so the levels broadcast follows it; next to a live runner the runner's 2 s poll steals the broadcast briefly, and the runner's own slot-9 device (9009) shares the bus, so its audition mirror is heard in the readings too. The private device stays in the engine's device list (on `silence`) afterwards. Exit 0 pass, 1 fail, 2 could not run/usage. | `npm run patch:audition -- <Name> [--engine auto\|running\|boot] [--quick\|--long\|--take <label>] [--params k=v,…] [--rest-max <dBFS>] [--src 9101] [--keep]` |
| `samples-check.ts` | Reads `samples/COS_<Name>/SHOPPING.md` (a `\| slot \| what \| length \| channels \| pitched \| licence \|` table, header and `\|---\|` separator both validated); matches files Ciaran dropped into that folder to slots by filename (basename starts with `<slot>-` or equals `<slot>.<ext>`, case-insensitive; a slot's several matches take the first sorted one, the rest are a warning naming the file that won). Converts the chosen file per slot to 48 kHz WAV (mono/stereo per the slot, noting any downmix/upmix) via ffmpeg into `wav/<slot>.wav`; a conversion failure is caught per slot (reported, does not abort the other slots). Merges the result into any `manifest.json` already on disk (`slot → file, frames, channels, sr, source, seconds`): this run's successes overwrite, and an entry is dropped only once its `wav/<slot>.wav` no longer exists — a slot whose source later goes missing keeps its old entry as long as the WAV is still there. Writes a `SOURCES.md` skeleton (`slot, file, url, author, licence`; written once, then only appended to for new slots — Ciaran's filled-in rows are never touched). Prints one line per slot (`ok`/`missing`/`unreadable`/`conversion failed`) plus one per extra file, then a summary. Exit 0 every slot converted (length warnings and same-slot duplicates allowed), 1 any slot missing/unreadable/failed-to-convert or a file matches no slot, 2 usage, no `SHOPPING.md`, a malformed `SHOPPING.md`/`SOURCES.md` (caught at the CLI as a usage error), or ffmpeg/ffprobe not installed (`install ffmpeg (brew install ffmpeg)`, nothing written). An existing `manifest.json` that is not a JSON object is treated as empty; entries without a string `file` are dropped. | `npm run samples:check -- COS_<Name> [--dir samples/]` |

`src/atomic.ts` — `writeAtomic`, used by every tool that edits a checked-in file (temp
path + rename, so a half-written file is never observable). `src/sc.ts` — `SCLANG`, `repoRoot`,
`airkitRoot`, `personalityPath`, `rosterPath`, `compileCheck` (the compile check `patch-compile.ts`
runs; the idiom is Glimmer's `tools/patch-compile.sh`).

Future work: `patch-audition.ts --partner-slot <n>` — audition a `2H` patch with `~partner` set
to a live slot's model instead of nil (today the tool always sends `partner 9 0`, so the partner
branch is checked with Ciaran live).
